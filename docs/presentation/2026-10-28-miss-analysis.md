## 원인 정리

1. **탐색이 닿지 못함 (G 6, 모두 Maison)**
   - 입력 검증 버그 5개 전부와 이동 1개다. 로그인이 필요한 계정 영역과 입력 폼까지 이어지는 흐름이 사이트 지도·계획에 들어오지 않았다(F9가 unplanned로 남음).
   - 입력 검증이 약하다기보다, 그 화면까지 탐색이 가지 못한 문제다.
   - 단, 6개 중 4개(V2·V4·V5·N4)는 제출·로그인 같은 서버 쓰기가 있어야 드러난다. 실행 기록에 이 흐름의 차단 흔적은 없다(가지 못했으므로). 탐색을 넓혀도 쓰기 허용 실행 없이는 잡지 못한다(표의 G→H). V1·V3는 쓰기 없이 화면에서 판정할 수 있어 순수한 탐색 부족이다.
2. **봤지만 검사로 이어지지 못함 (B 1 + C 4 + E 2 + F 3 = 10)**
   - 관찰(observations)에 적은 이상이 검사로 바뀌지 않는다. 관찰을 검사로 바꾸는 단계가 없다.
   - 이동 검사가 "주소가 바뀌었나·도착했나"만 확인하고, 이동 전 상태·뒤로 가기 같은 앞뒤 문맥을 보지 않는다(N1, N3).
   - 같은 컨트롤의 값 변화만 보고, 상태와 표시가 일치하는지는 계획하지 않는다(U2~U4).
3. **실행 조건상 확인 불가 (H 3, 모두 Adminator)**
   - 저장하거나 다른 사용자 화면에서 봐야 드러나는 버그다. 쓰기 차단과 서버 오류 때문에 확인하지 못했다.
   - Maison G→H 4개를 더하면 쓰기가 필요한 버그는 최소 7개(놓친 19개의 3분의 1 이상)다.
