# 서비스 기획 재검토 검증 기록

검증일: 2026-10-10 · 조사·문서 편집만 수행

## 검토 범위와 결과

- 현재 source와 기존 조사 기록을 대조해 Dashboard·Sidebar의 동작 기능과 샘플을 구분했다. 현재 source를 기준으로 했으며 이번에는 실행 화면을 재탐색하지 않았다.
- Dashboard/Sidebar 제안 W01–W16을 중복 없이 정리했다. 16개 모두 현재 상태·추가/개선·이유·사용 시나리오·화면과 클릭·기존 기능 연계·난이도를 포함하는지 문서 구조 검사로 확인했다.
- Calendar Agenda·RSVP·메일 답장/임시저장·Tasks CRUD·계정 전환은 이미 구현된 기능으로 구분했다. 신규 범위는 해당 기능의 화면·검색·데이터 확장·연결 개선이다.
- 서비스 가치 평가 5개 기준의 가중치는 합계100%이다. 구현 용이성은 점수가 높을수록 쉽다. 테스트 자동화/버그 인젝션은 우선순위 점수에 포함하지 않았다.
- 16개 제안을 평가표와 단계별 로드맵에 대응시켰다. 높은 가치와 개발 선후 관계를 분리하고 업무 요청/장소는 수요 확인 후 선택하도록 했다.
- Codex 전용 문서의 우선 참조 규칙과 사람용 요약의 컨텍스트 제외 규칙을 명시했다. 과거 제안은 보관 문서로 분리했다.
- 상대 Markdown 파일 링크를 검사했다. 최신 문서에서 아직 구현되지 않은 메뉴를 현재 실행 링크처럼 제시하지 않았다.

## 해석의 한계

점수와 서비스 방향은 현재 구현 구조에 근거한 기획 판단이다. 실제 사용자 조사·사용 빈도·운영 규모의 측정값이 아니다. 비용·기간은 산정하지 않았고 난이도는 필요한 데이터/API/화면 변경 범위에 따른 상대 평가다. 기존 테스트 결과는 당시 기록으로만 취급하며 이번 기획으로 새로운 실행 검증을 완료했다고 주장하지 않는다.
