# 현재 서비스와 개발 상태 요약
갱신: 2026-10-10 · 사람용 설명

이 문서는 사람이 진행 상태를 빠르게 이해하는 자료다. **Codex는 이 문서를 작업 컨텍스트로 사용하지 않고 docs/PROPOSAL_WORK_CONTEXT.md를 먼저 참조한다.**

## 현재 서비스
Adminator는 개인 업무와 공유 소통을 연결하는 내부 협업 공간으로 발전했다. 기존 계정/다중 계정 전환·일정/반복/참석 응답·공유/개인 채팅·내부 메일 위에 업무 홈과 실제 업무 화면을 구현했다.

업무 메뉴는 Home/My tasks/Calendar/Work report, 협업 메뉴는 Email/Chat/People/Needs attention이다. 내 프로필·환경설정·계정 전환은 계정 메뉴에서 접근한다. UI/버튼/지도 샘플은 업무 메뉴에서 분리하고 기존 URL로 남겼다.

## 이번에 사용할 수 있게 된 기능
- 홈: 오늘/다가오는 일정·미완료 할 일·최근 메일/대화·실제 요약 수치·확인할 항목. 판매/날씨/방문 샘플은 제거했다.
- 내 할 일: 검색·완료/미완료/오늘/지연 필터, 메모·마감 날짜·중요도, 저장/삭제/완료 기록.
- 업무 연결: 메일·일정·메시지에서 개인 후속 할 일을 만들고 원본으로 다시 이동한다. 원본이 없어져도 할 일은 남는다.
- 설정: 실제 표시명·시간대·테마·일정 범위·홈 카드·메일 자동 갱신을 계정별로 저장한다. 미저장 입력이 있으면 이동/계정 전환 전에 안내한다.
- 구성원/메일: 활성 구성원과 내부 주소를 찾아 메일/개인 채팅으로 연결한다. To/Cc/Bcc에 구성원을 선택하고 inbox를 갱신할 수 있다.
- 일정/채팅: 나와 관련된 일정 필터와 공유 범위 안내, 변경 충돌 시 최신 버전 확인. 채팅방 즐겨찾기·메시지 검색/직접 이동.
- 검색/확인할 항목/리포트: 접근 가능한 업무 자료를 찾고, 미응답 초대·안 읽은 메일/대화·마감 할 일을 확인한다. 완료 날짜가 기록된 보존 할 일은 기간별 리포트로 본다.

기존 개인 자료를 공유로 바꾸거나 DB를 초기화하지 않았다. 개인 할 일·메일·설정은 현재 계정 기준이다. 신규 공유 일정과 방은 기존 정책대로 인증된 사용자에게 공유된다.

## 검증과 다음 방향
기존 프런트엔드 테스트122개·백엔드44개 통과, 데스크톱/모바일 실제 흐름·계정 분리·화면 검증, 빌드 완료. 로컬 사이트는 http://127.0.0.1:8000 에 반영했다.

제안서1–3단계의 기본 서비스 범위를 구현했다. ‘업무 요청’과 ‘장소’는 실제 수요 확인이 조건이므로 아직 구현하지 않았다. 자유 홈 배치·더 큰 검색/이력·세밀한 충돌 비교는 후속 확장이다. 외부 이메일·첨부·조직/관리자 권한·운영용 다중 서버는 현재 범위에 없다.
