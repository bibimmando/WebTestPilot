# 여러 계정 로그인과 빠른 전환

기준일: 2026-10-10. 실제 회원 데이터를 삭제하지 않고 현재 브라우저에 로그인한 계정들을 전환하는 기능이다.

## 계정 추가

1. 평소처럼 로그인한다.
2. 사이드바 하단 사용자 프로필 아래의 **Switch Account**를 누른다. 모바일은 먼저 왼쪽 메뉴를 연다.
3. **Add account**에서 Username 또는 내부 Email과 Password를 입력한다.
4. **Sign in and add**를 누른다. 정상 로그인된 계정만 목록에 추가되고 바로 활성화된다. 다른 등록 계정은 로그인 상태를 유지한다.

잘못된 비밀번호이면 기존 계정을 유지하고 오류를 표시한다. 이미 등록된 계정을 다시 인증하면 중복 항목이 생기지 않는다. 브라우저마다 최대10개를 등록할 수 있다.

## 전환

Switch Account 목록에서 원하는 계정을 누른다. 현재 계정은 체크와 Current account로 표시된다. 각 항목에 프로필 아이콘, Username, 내부 Email을 표시한다. 목록이 길면 스크롤한다.

이미 인증한 유효 계정은 비밀번호 없이 전환한다. 현재 페이지 URL을 유지하면서 다시 로드하고 개인 메일함/프로필/Dashboard를 새 계정으로 바꾼다. 공유 Chat과 Calendar는 유지하며 발신자/작성자/수정자/읽음 상태는 활성 계정을 따른다. 저장하지 않은 입력은 전환 시 사라지므로 필요한 내용은 먼저 저장한다.

## 제거

원하는 항목의 **Remove**를 누른다. 해당 브라우저의 등록과 서버 측 전환 권한을 실제로 폐기한다. 다시 사용하려면 Add account에서 비밀번호를 입력해 로그인해야 한다. 회원 계정, 메일, 채팅 메시지, 일정과 다른 브라우저 로그인은 유지한다.

활성 계정을 제거하면 남아 있는 유효 계정으로 전환한다. 유효한 대체 계정이 없으면 로그인 화면으로 이동한다. 제거에 실패하면 오류를 표시하고 기존 계정/목록을 유지한다.

## Log out과 차이

| 동작 | 의미 |
|---|---|
| Switch Account | 이미 등록된 계정으로 전환 |
| Add account | 비밀번호로 다른 계정을 인증·추가 |
| Remove | 선택한 계정을 이 브라우저에서 로그아웃·목록 제거 |
| Log out | 현재 활성 계정만 로그아웃·목록 제거 |

Log out 후 다른 유효 계정이 있으면 그 계정으로 전환한다. 다른 계정도 모두 끝내려면 목록에서 각 계정을 Remove한다. 전체 로그아웃 API는 있지만 별도 UI 버튼은 현재 제공하지 않는다.

## 구현 상태와 제한

추가·전환·제거·대체 계정·새로고침 유지 및 PC/모바일 UI를 구현했다. 쿠키는 HttpOnly이며 비밀번호와 인증 토큰을 브라우저 저장소에 저장하지 않는다. 서버는 현재 브라우저에 인증된 계정인지, 만료되거나 비활성화되지 않았는지 확인한다.

로그인 만료 시 다시 비밀번호 인증을 해야 한다. 빠른 전환만으로 로그인 시간을 무한 연장하지 않는다. 한 브라우저의 모든 탭은 같은 활성 계정을 사용하며 계정이 바뀌면 다른 탭도 다시 로드한다. 공유 PC에서는 사용을 마친 계정을 Remove하여 다른 사람이 전환하지 못하도록 한다.
