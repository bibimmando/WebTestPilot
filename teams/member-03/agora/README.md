# Agora

관심사별 커뮤니티 사이트. 웹 테스트 에이전트를 평가하기 위한 테스트 대상(WTP)으로 만들었다.
화면(React + Vite)과 API(Vite 플러그인)가 한 포트에서 돌고, 자료는 메모리에만 둔다.

## 실행

```bash
npm install
npm run dev        # http://127.0.0.1:8090
npm run typecheck
```

## 테스트 장치

| 요청 | 하는 일 |
|---|---|
| `POST /_reset` | 모든 자료를 시드 상태로 되돌린다. 매 실행 전에 부른다. |
| `POST /_reset` `{"seed": 42}` | 되돌리면서 게임 시드를 고정한다. 카드 배치 · 불 끄기 판 · 업다운 정답 · 다섯 글자 단어가 늘 같다. `{"seed": null}` 은 끈다. |
| 환경 변수 `AGORA_SEED=42` | 서버를 띄울 때의 기본 게임 시드. 본문 없이 `/_reset` 을 부르면 이 값으로 돌아간다. |
| 화면 주소 `?seed=7` | 그 게임 화면에서만 시드를 바꾼다 (`/games/lights?seed=7`). |
| `GET /api/bugs` · `GET /gt.json` | 켜져 있는 결함 목록과 정답. 검사 대상 모델에는 주지 않는다. |
| `BUGS_ON=all` · `BUG_F1=1` | 결함 켜기 (`server/bugs/`). 기본은 모두 꺼진 정상 사이트. |

시드 글의 시각은 "지금으로부터 몇 분 전" 으로 정해져 있어 언제 띄워도 정렬 결과가 같다.
