# 탐색과 판단

페이지 목록을 기계적으로 모두 실행하지 않는다. 크롤러 문맥에서 중요한 사용자 흐름을 정하고 실제 관찰에 따라 다음 행동을 고른다. 기능 버튼, 폼, 이동, 표시 상태와 경계 입력을 살핀다. 후보를 발견하면 당시 조건과 증거를 즉시 보존한다. 버그 개수 목표나 고정 반복 횟수를 두지 않는다.

상태가 바뀌면 locator와 조건을 다시 확인한다. 알려진 요소·URL·제품 상태를 완료 조건으로 사용한다. networkidle과 고정 sleep을 범용 완료 조건으로 사용하지 않는다. 클릭 강제 실행, JS 합성 이벤트, 네트워크 mock은 사용자 행동 재현과 분리된 진단 실험으로 표시한다.

기대, 관찰, 추론, 외부 문서 진술을 나눈다. 반대 증거와 환경/테스트 오류를 검토한다. 재현 상태와 결함 판정은 독립적이다. 보고서에는 판정 이유, 불확실성, 남은 테스트를 남긴다. 원본 Dogfood의 항상 영상 요구·비재현 후보 제외·5~10개 이슈 목표는 적용하지 않는다.
