# Functional

버튼·폼·체크박스·선택·키보드 조작의 전후 상태와 제품 완료 조건을 비교한다. 이벤트 실행 여부만으로 사용자 기능 성공을 추정하지 않는다. disabled, 가림, locator 개수, 타임아웃을 진단하고 정상적인 접근 방법을 먼저 시도한다. console error나 HTTP 오류는 영향과 행동의 인과관계를 확인한다.

원본 근거: `skill-data/core/SKILL.md`의 Interacting/Waiting, `skill-data/dogfood/references/issue-taxonomy.md`의 Functional. 외부 공식 문서는 제공되지 않았으므로 사건별 실제 원문 확인 후 인용한다.
