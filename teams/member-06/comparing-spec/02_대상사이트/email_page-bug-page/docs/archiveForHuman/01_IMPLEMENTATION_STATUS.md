# 현재 개발 현황


## 2026-10-12 테스트용 버그 명세 준비 완료

이 프로젝트는 웹 테스트 에이전트가 문제를 얼마나 잘 찾아내는지 평가하는 샘플 사이트다. 정상 웹사이트를 기준 버전으로 보존하고, 향후 별도 Git 버전에서 코드에 결함을 직접 넣어 비교한다. 정상 버전과 결함 버전은 배포된 코드로 구분한다.

버그는 기능(F), 입력 검증(V), 이동·라우팅(N), UI(U) 네 유형으로 관리한다. [버그 명세 가이드](../bugDocs/bugs.md)와 유형별 문서에 고유 ID, 정상/결함 동작, 재현 절차, 탐지 방법, 검증 결과를 기록한다. 정답 문서는 평가자와 개발자용이며 테스트 에이전트가 보는 사이트에는 공개하지 않는다.

현재는 문서와 템플릿 정리가 완료됐고 실제 주입 버그는 0건이다. 기능·라우팅·UI 예시와 과거 입력 검증 5건은 모두 미구현이다. 이번에는 기능이나 DB를 변경하지 않았다. 다음 단계는 정상 기준과 테스트 데이터를 고정하고 현재 기능에 맞는 명세를 확정한 뒤, 개별 결함 구현과 통합 검증을 진행하는 것이다. 버그 ON/OFF 시스템은 사용하지 않는다.


기준일: 2026-10-11. 실제 소스 기준으로 기본 협업·개인 업무 기능이 구현되어 있다. 전체 운영 준비나 원래 제안의 모든 확장을 완료했다는 뜻은 아니다.

| 영역 | 지금 사용할 수 있는 기능 |
|---|---|
| 계정 | 회원가입·로그인·세션 만료·표시명 수정, 최대10개 로그인 계정 전환/제거 |
| 업무 홈 | 오늘/다가오는 일정, 미완료 할 일, 미읽음 메일/채팅, 최근 자료·확인할 항목 |
| 개인 할 일 | 검색·필터, 메모·마감·중요도, 완료/삭제, 메일·일정·메시지 원본 연결 |
| 설정 | 시간대·테마·홈 카드·일정 기본 범위·메일 자동 갱신, 브라우저 전체 계정 로그아웃 |
| 일정 | 공유/기존 비공개 일정, CRUD·반복·참석 응답·Agenda·충돌 안내 |
| 채팅 | 전체 공유 방·1:1, 실제 송수신·읽음·이력, 즐겨찾기·메시지 검색 |
| 내부 메일 | 등록 계정 To/Cc/Bcc, 답장·전달·초안·읽음·별표·폴더·검색, UI 전송 재시도 중복 방지 |
| 구성원·검색 | 활성 구성원 공개 연락처와 메일/대화 연결, 접근 가능한 업무 내용 검색 |
| 확인할 항목·리포트 | 마감 할 일·미응답 초대·미읽음 자료, 보존 할 일의 완료 날짜 집계 |

설정·리포트가 실제 기능이므로 예전 Forms/Charts/Blank URL도 해당 역할로 연결된다. Basic Table은 일정 Agenda, Data Table은 Tasks로 이동한다. 판매·날씨·방문 샘플은 업무 홈에서 제거했다.

아직 없는 기능은 외부 SMTP/IMAP·실제 메일 첨부·조직/관리자 권한·업무 요청·장소 관리다. 반복 일정은 시리즈 전체만 편집하고 리포트는 삭제된 업무까지 포함하는 감사 로그가 아니다. 일정 범위와 카테고리 선택 충돌을 수정했다. 개인 샘플 복원은 공유/초대 일정을 보존하고, 저장 뒤 화면 갱신 실패도 저장 실패와 구분한다.

이번 품질 개선은 필터·이름 검증·조회 부작용·채팅 재시도/계정 전환·개발 연동을 보완하고, 기존 DB를 보존하는 격리 검증을 수행했다. 프론트130개·백엔드62개와 lint/build 및6개 브라우저 검증이 통과했다. 자세한 결과는 검증 안내에 기록한다. 원격 운영 서버/DB 상태는 검사하지 않았다. 기능 전체가 모든 환경에서 검증되었다는 의미로 확대하지 않는다. [검증 안내](07_TESTING_GUIDE.md) · [남은 과제](09_DEVELOPMENT_ROADMAP.md)

이번 변경의 문제별 처리와 남은 항목은 [개선 보고서](PROJECT_IMPROVEMENT_REPORT.md)에 정리했다. 외부 메일·조직 권한·다중 서버 실시간 기능은 후속 범위다.

## Email Label 개선 완료

Label 개수의 undefined 표시, 필터 해제 불가, 선택 표시 부재, 메일함 전환 후 필터 유지 문제를 해결했다. 현재 계정의 전체 메일(Spam/Trash 포함) 기준 숫자와 상단 해제 버튼을 사용할 수 있다. 이번 수정 후 프론트135개 테스트, lint/build, Mock 및 실제 내부 메일의 데스크톱/모바일 브라우저 검증이 통과했다. [사용 방법](05_FEATURE_GUIDE.md) · [상세 결과](EMAIL_LABEL_IMPROVEMENT_REPORT.md)
