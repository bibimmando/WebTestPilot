# 남은 과제와 개발 방향

기준일: 2026-10-11. 현재 기본 내부 협업 기능 위에 정확성·운영 안정성·자료량 대응을 개선하는 단계다.

| 방향 | 남은 일 |
|---|---|
| 완료한 개선 | 일정 필터·공통 이름 검증·조회 부작용 제거·Reset 자료 보호·채팅 재시도·개발 프록시 |
| 운영 안정성 | 여러 서버의 채팅 알림, 전송/저장 제한, 만료된 브라우저 로그인 정리 |
| 자료량·검색 | 메일·Chat·일정 전체 로딩 개선, 서버 검색/페이지/기간 조회 |
| 동시 편집·시간 | 초안 충돌 보호·메일/일정 retry 계약, 반복 발생일 예외·DST 입력, 일정 이전 preview |
| 업무 기록 | 삭제·변경까지 보존하는 이력과 정확한 리포트 정의 |
| 메일 확장 | 실제 첨부 권한/검사/저장, 필요 시 외부 메일 공급자 |
| 조건부 제품 | 실제 수요가 확인된 업무 요청·장소·조직별 권한 |

업무 요청/장소는 아직 없다. 자유로운 홈 카드 재배치, 방 숨김/음소거, 비밀번호 재설정/MFA/OAuth와 운영 감사도 후속 범위다. 현재 계정은 조직 권한 모델이 아니며 공유 자료는 전체 인증 사용자에게 보인다.

Calendar는3초, 메일/상단 목록은30초 갱신이며 Home은 자동 push가 아니다. 채팅 실시간 연결은 단일 서버 프로세스에 의존한다. 리포트는 보존된 할 일의 완료 날짜만 보여 주므로 장기 감사 기록을 대신하지 않는다. 외부 지도·실제 휴대전화 터치·HTTPS/PostgreSQL은 추가 확인이 필요하다.

개발할 때 기존 개인 자료를 자동 공유하거나 DB 초기화로 문제를 해결하지 않는다. 상세 제약은 [알려진 문제](../docs/KNOWN_ISSUES.md), 기술 계획은 [개발 로드맵](../docs/ROADMAP.md)에 모았다.
